# Prototipo original

Estos archivos son el prototipo en HTML, CSS y JavaScript con el que empezó Duelist's Forge. La aplicación vigente es el proyecto Angular 22 en la raíz del repositorio.

Para abrir el prototipo, sirve esta carpeta con cualquier servidor estático y visita `index.html`. No forma parte del build de Angular.

```bash
cd legacy
python3 -m http.server 8080
```
